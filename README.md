### Projects

**SSO System** — A custom Single Sign-On system built from scratch for a multi-product company, so users can log in once and access multiple products without separate credentials for each. Designed the IdP (Identity Provider) and SP (Service Provider) architecture, the database models, and the core Flask endpoints. Implemented an OpenID Connect–style authorization code flow, with JWTs signed using RS256 for secure, verifiable tokens across services.

**Endeavour** — An ecommerce website covering the core shopping flow — browsing products, adding to cart, and checkout — built with HTML, CSS, and JavaScript.

**RKMVMFamily** — The official website of my college, which I'm currently developing and maintaining. Covers the college's information, announcements, and related content for students and visitors.

**College Magazine Portal** — A centralized web portal that brings together all of my college's student publications (annual magazines, departmental journals, and hostel/bhavan publications) in one place, organized by academic year and category. Built with Flask on the backend and vanilla HTML/CSS/JS on the frontend, with session-based auth, CSRF protection, and rate limiting. Includes a sandboxed in-browser reader with desktop/tablet/mobile preview modes and an admin panel for uploading new editions.
